## Methodology

Each entry is sourced from an academic paper, press release, government filing, or verified industry report.
The `transhumanists/apis` pipeline runs every 6 hours via GitHub Actions, parsing 80+ RSS feeds, running LLM-based milestone extraction, and committing updated JSON to this repository.

### Scoring Formula

```
milestone_score = log10(value / baseline) * 100 + recency_bonus
recency_bonus    = max(0, 30 - days_since_publication)
```

### Subcategory Normalization

All values are normalized to a 0–100 "progress score" relative to the theoretical maximum in each subcategory.
Baseline = lowest value ever recorded. Ceiling = physical/theoretical limit.
